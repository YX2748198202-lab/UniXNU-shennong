# Root policy files

`verified-root-key.bin` is the public half of this board's root signing key (395 bytes:
magic, 3072-bit modulus, exponent 0x010001). `OS.policy` and `SystemOS.policy` are the
544-byte signed headers for the two SHNGROOT windows; the matching block hash tables live
in the root image as the objects `OS.vroot` and `SystemOS.vroot`.

They are generated by `scripts/make-root-policy.py` from the written root image, which is
also where the APFS volume UUIDs come from. The private key is deliberately not stored
here: regenerating these files needs it, booting the board does not.
